# Telegram-бот «Кіногід» — клієнт до REST API (PLAN.md)

Console-застосунок net8.0 (Telegram.Bot 22.x, long polling). Жодної власної логіки даних —
усе через `API_URL` (дефолт `http://api:5200`).

## Конфігурація (env)

| Змінна | Опис |
|---|---|
| `TG_BOT_TOKEN` | токен від BotFather. Порожній → бот логує «TG_BOT_TOKEN порожній — заповніть .env» і чекає (лог раз на 30 с), не падає. |
| `API_URL` | база REST API, дефолт `http://api:5200`. |

## Команди

- `/start` — привітання + інлайн-меню
- `/help` — список команд (укр/англ)
- `/search <назва>` — пошук, 10 результатів на сторінку, кнопки «➕ Хочу подивитись» / «✅ Переглянув» і пагінація
- `/similar Назва1; Назва2; ...` — 1–10 еталонів (розділювач `;`); кожну назву бот резолвить
  через `GET /api/search?pageSize=1`, потім `POST /api/similar/by-seeds` → топ-10 з причинами
- `/text <опис побажання>` — `POST /api/similar/by-text` (503 → дружнє повідомлення)
- `/watchlist [сторінка]`, `/watched [сторінка]` — списки профілю 1 з оцінками
- `/lang uk|en` — мова чата (in-memory; після рестарту скидається на uk — свідоме спрощення Е0/Е1)

Текст без `/` теж трактується як пошуковий запит.

## Формат

HTML parse mode, усі динамічні рядки екрановані. Постери не надсилаються (Е0/Е1).
Картка: назва + рік + рейтинг + опис (~300 символів) + reasons + посилання TMDB
(`/movie/{tmdbId}` для фільмів, `/tv/{tmdbId}` для серіалів і шоу).
Довгі відповіді автоматично розрізаються на кілька повідомлень (< 4096 символів).

## Структура

```
Program.cs            — конфіг, очікування токена, long polling
Api/                  — HttpClient до API, моделі (TitleCard тощо), ApiResult
Bot/CommandParser.cs  — парсери команд/аргументів (юніт-тестуються)
Bot/TextFormatter.cs  — HTML-екранування, обрізання, емодзі, TMDB-посилання
Bot/Renderer.cs       — складання повідомлень + розрізання на чанки
Bot/Keyboards.cs      — інлайн-клавіатури
Bot/Strings.cs        — uk/en тексти
Bot/ChatState.cs      — in-memory мова чата + останній пошук
Bot/BotUpdateHandler.cs — сценарії команд і кнопок
tests/                — xunit (парсери, форматування, API-мапінг)
```

## Розробка

```bash
dotnet build   # 0 помилок
dotnet test    # 0 провалених
TG_BOT_TOKEN=123:abc API_URL=http://localhost:5200 dotnet run
```
