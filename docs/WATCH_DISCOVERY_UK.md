# Пошук джерел перегляду

## Що бачить користувач

Панель «Де подивитись» показує пропозиції для вибраної країни й глобальні пропозиції. Фільтр мов працює за заявленими аудіодоріжками або субтитрами. Посилання TMDB ведуть до регіонального каталогу з даними JustWatch. Мова пошукового запиту й країна пошуку не визначають мову аудіо, ціну чи права на перегляд. [Документація TMDB](https://developer.themoviedb.org/reference/movie-watch-providers)

До довідника додано офіційні каталоги для фільмів і серіалів, зокрема [RTVE Play](https://www.rtve.es/play/), [RaiPlay](https://www.raiplay.it/), [ABC iview](https://iview.abc.net.au/), [SBS On Demand](https://www.sbs.com.au/ondemand/), [PBS](https://www.pbs.org/), [CBC Gem та ICI TOU.TV](https://site-cbc.radio-canada.ca/documents/impact-and-accountability/ati/board-meetings-senior-executive-committee/2020-05-06/5.1-ott-hamornization-update.pdf), а для аніме — [Crunchyroll](https://www.crunchyroll.com/), [BiliBili](https://www.bilibili.tv/en/anime) і [d Anime Store](https://animestore.docomo.ne.jp/animestore/CH/danime). Ці каталоги можна відкрити навіть без Brave Search.

## Як працює автоматичний пошук

- За наявності ключа TMDB запити у фоновій черзі перевіряють усі регіони в одному знімку пропозицій. Плановий обхід охоплює обмежений набір популярних і нещодавно оновлених тайтлів. Решта тайтлів стає в чергу після відкриття панелі, якщо в каталозі є TMDB або IMDb ID.
- Додатковий Brave Search шукає сторінки за назвою, роком і локалізованим терміном перегляду. Пошук доступний для UA, PL, DE, FR, IT, ES, GB, US, CA, AU, JP, ID, MY, PH, SG, TH і VN. Якщо окремого ринку Brave немає, використовується всесвітній індекс із параметрами локалізації. Вебпошук потребує відомого року та наявної в каталозі назви. [Документація Brave Web Search](https://api-dashboard.search.brave.com/api-reference/web/search/get)
- Виклики Brave працюють у фоновій черзі та не затримують відповідь API тайтла. Плановий пошук за замовчуванням ставить у чергу один популярний тайтл на годину та змінює країну між циклами. Загальний бюджет за замовчуванням становить 32 запити на добу UTC, з урахуванням запитів зі сторінок тайтлів. Ліміт зберігається в БД.
- Посилання на тайтли з відомих офіційних доменів з’являються в секції «Посилання з вебпошуку». З незнайомих доменів в окрему чергу перевірки потрапляють щонайбільше два збіги за запит. Публічна панель показує їх після схвалення адміністратором. Воркери не відкривають знайдені сайти. Доступність сеансу, повнота відео, ціна і мови позначаються як невідомі. Застарілі вебпосилання приховуються через 30 днів після останнього підтвердженого збігу пошуку.

## Налаштування та перевірка нових сайтів

Для серверного Compose задайте `WATCH_WEB_ENABLED=true`, `BRAVE_SEARCH_API_KEY` і, за необхідності, `WATCH_WEB_DAILY_REQUESTS`. Для прямого запуску API відповідні назви — `WatchWeb__Enabled`, `WatchWeb__ApiKey`, `WatchWeb__DailyRequests`. План Brave має надавати права на зберігання результатів. У базі зберігаються посилання та прив’язка до тайтла, країни і джерела. [Умови зберігання результатів Brave](https://brave.com/search/api/#faq)

1. Запитайте `GET /api/admin/watch/sources` із заголовком `X-Admin-Key`. Відповідь містить до 100 кандидатів від нових доменів. Для наступної сторінки передайте `before` з останнім отриманим ID.
2. Перевірте сторінку: назву, рік, тип тайтла, країну й відповідність посилання потрібному фільму або серіалу. Схвалення стосується конкретного посилання.
3. Надішліть `POST /api/admin/watch/sources/{id}/review` із тим самим заголовком та JSON із полями `approve` (булеве значення) і `url` (точний URL із відповіді пошуку). Схвалене посилання стає видимим у відповідній країні, відхилене лишається прихованим.
